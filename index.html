Marque atividades para agrupá-las. Use ↑ ↓ para mover uma atividade individualmente ou ⇧ ⇩ para mover o grupo inteiro. A coluna Descrição tem quebra automática de texto e altura ajustável. Cada linha tem seu próprio cronômetro com Play, Pausar e Zerar. Clique no texto para editar. A ordem exibida e os tempos registrados serão exportados.
Os dados são salvos automaticamente neste navegador. Para uma cópia de segurança, exporte o Excel. Ao importar uma planilha, os cronômetros são reiniciados. Exporte seu arquivo para guardar as alterações. A importação e exportação de Excel usam a biblioteca SheetJS; na primeira utilização, é necessária conexão com a internet para carregá-la.
