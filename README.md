Painel SMED
Aplicação web para organização e acompanhamento das atividades de SMED.

Funcionalidades
Cadastro de atividades
Cronômetro por atividade
Agrupamento de atividades
Registro de início, fim e duração
Múltiplas coletas
Importação de Excel e CSV
Exportação dos resultados
Salvamento automático
Acesso
O sistema foi desenvolvido em HTML, CSS e JavaScript e pode ser utilizado diretamente pelo navegador.
